プライバシーポリシー

suno_uploader は、運営者本人の YouTube チャンネルを管理するための個人用ツールです。

  • 使うデータ：運営者本人のチャンネルの動画情報と、YouTube Analytics・Reporting の集計データだけです。
  • 使い道：動画の投稿・予約、概要欄やコメントの管理、再生数などの集計にだけ使います。
  • 第三者への提供：しません。広告や販売には使いません。
  • 保存：運営者本人の端末にだけ保存します。
  • Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  • 許可の取り消し：Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

Privacy Policy (English)

suno_uploader is a personal tool used only by its operator to manage the operator's own YouTube channels.

  • Data used: only the operator's own channel and video information, and YouTube Analytics / Reporting data for those channels.
  • Purpose: uploading and scheduling videos, managing descriptions and comments, and aggregating view statistics.
  • Sharing: data obtained through YouTube API Services is never shared with or sold to third parties.
  • Storage: data is stored only on the operator's own computer.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time from "Third-party apps & services" in your Google Account.
